
# Expense Tracker CLI

A simple command-line expense tracker built with Python.

## Features

- Add expenses
- View expenses
- Calculate total expenses
- Delete expenses
- Edit expenses
- Category-wise expense summary
- Search expenses
- JSON data persistence
- Input validation

## Technologies

- Python
- JSON
- Git
- GitHub
