# Expense Tracker CLI

A command-line expense tracker built with Python, featuring local JSON storage and an AI assistant powered by Ollama.

## Features

### Expense Management

- Add expenses
- View all expenses
- Edit expenses
- Delete expenses
- Calculate total expenses
- Category-wise expense summary
- Search expenses
- Automatic date tracking
- Input validation
- JSON data persistence

### Sorting

Expenses can be temporarily sorted by:

- Amount
- Date
- Category
- Description

Both ascending and descending order are supported.

### AI Assistant

The project includes an AI assistant powered by Ollama and Qwen 2.5 3B.

The AI assistant can:

- Calculate total expenses
- Generate category summaries
- Search expenses
- Add expenses
- Edit expenses
- Delete expenses
- Sort expenses
- Understand natural-language expense requests
- Use tool calling to interact with the expense tracker

Examples:

```text
Show my total expense.

Add ₹500 for lunch.

Delete my coffee expense.

Change my petrol expense to ₹1500.

Sort my expenses from highest to lowest.

Show my newest expenses first.

Sort my expenses alphabetically by category.
